# 予約受付台帳 — STEP 1

Windowsのローカル環境で動作する、予約受付システムのUIデモです。参考画像のベージュ系の配色、週間カレンダーと予約一覧、予約確認ダイアログを再現しています。HTML / CSS / JavaScriptのみを使用し、外部ライブラリ・サーバー・ビルド・データベースは不要です。

## フォルダ構成

```text
reservation-system/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── samples/
│   └── スケジュールサンプル_202607_202610.ics
└── README.md
```

サンプルICSは既存のファイルをそのまま保持しています。実際のファイル名の濁点は結合文字で保存されていますが、リネームや内容の変更は行っていません。2026年7月〜10月のテスト用データはSTEP 2で使用します。

## 起動方法

1. このフォルダの `index.html` を右クリックします。
2. 「プログラムから開く」からMicrosoft Edgeを選択します。
3. サーバーを起動せず、`file:///.../reservation-system/index.html` で利用できます。

文字コードはUTF-8です。インターネット接続は不要です。ファイルを編集した場合はブラウザを再読み込みしてください。

## 実装したUI

- 上部のアプリ名・当日の日付、ベージュ系の台帳デザイン。
- ファイル選択・ドラッグ＆ドロップとファイル名の表示、選択のクリア。ファイル内容の読み込み・ICS解析は行いません。クリアしても仮データは残ります。
- 月〜金、9:00〜18:00の30分枠（最終枠17:30〜18:00）。前週・次週・今週へ移動できます。過去の日付に制限はありません。
- 緑＝空き、グレー＝予定あり、淡い赤＝予約済み。予定ありのパターンは各週に表示する仮データです。予約2件はページを開いた時点の今週に固定され、一覧も全件を表示します。
- 空き枠から予約入力ダイアログを開き、キャンセル・×・Escで閉じられます。予約確定ボタンは未実装のため無効です。閉じた入力は保存されず、次回表示時にリセットします。
- 氏名・メールアドレス・日時・状況を含む予約一覧2件。キャンセルボタンは未実装のため無効です。氏名・連絡先は見本です。
- `#admin` へのリンクと管理者画面の骨組み、受付画面への戻るリンク。アクセス制限のないデモであることを明示しています。
- 狭い画面ではカレンダーと一覧を縦並びにし、カレンダー内を横スクロールできます。

## 未実装の機能

ICS解析、空き時間の自動判定、予約確定、予約重複チェック、キャンセル処理、本人確認、localStorageへの保存、管理者認証・予約管理処理、メール送信は実装していません。再読み込みすると初期表示に戻ります。実際の個人情報を入力する必要はありません。

## 動作確認の手順

1. Edgeで直接開き、5日×18枠の週間カレンダーと予約一覧2件が表示されることを確認します。
2. 前週・次週で日付が7日ずつ移動し、今週で現在の週に戻ることを確認します。前週を繰り返せば2026年7月〜10月にも移動できます。
3. 緑の空き枠を押し、選択日時・氏名・メール欄があるダイアログが開くことを確認します。
4. キャンセル・×・Escで閉じられることを確認します。
5. 管理者リンクと戻るリンクを確認します。
6. F12のConsoleで重大なJavaScriptエラーがないか確認します。
7. ウィンドウを狭め、縦並びとカレンダーの横スクロールを確認します。
